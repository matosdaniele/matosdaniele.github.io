# Dicas da Dani

Tutoriais e trilhas para quem tem interesse em dados.

Site: [matosdaniele.github.io](https://matosdaniele.github.io/)

O blog se organiza em quatro caminhos:

1. **Fundamentos de Dados** — modelagem, o que é um banco, arquitetura, OLTP e OLAP
2. **Banco de Dados (SQL & NoSQL)** — consultas, otimização, administração e ETL
3. **Análise e Visualização** — Power BI, Tableau, dashboards e storytelling
4. **Programação para Dados** — Python (Pandas, NumPy) ou R para limpeza e manipulação

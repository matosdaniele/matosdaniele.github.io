Trilha 04

Programação para Dados

O dado raramente chega pronto. Esta trilha cobre Python (Pandas, NumPy) e R na manipulação e na limpeza da base.

Nesta trilha

  1. Python para dados — o fluxo básico: ler, inspecionar, transformar.
  2. Pandas e NumPy — tabelas, nulos, tipos, agrupamentos e o que quebra na prática.
  3. R — quando a análise estatística pede outra linguagem.
  4. Limpeza de dados — duplicatas, categorias bagunçadas, datas e o contrato com o relatório.

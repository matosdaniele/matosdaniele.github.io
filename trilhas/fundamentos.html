Trilha 01

Fundamentos de Banco de Dados

Antes de administrar, entender o que está guardado: o dado em bits, os tipos que o banco aceita, como o SQL Server organiza tudo em disco e como o modelo explica a si mesmo.

Nesta trilha

  1. Do bit ao byte — como o computador representa o dado antes de qualquer tabela.
  2. Tipos de dados — número, texto, data, nulo: o que cada tipo permite, quanto ocupa e o que quebra na prática.
  3. Como o SQL Server guarda o dado — páginas de 8 KB, extents e os arquivos de dados e de log.
  4. Modelagem e documentação — chaves, relacionamentos e o significado de cada objeto guardado no próprio banco.

Tutoriais

  1. Estrutura de dados - Sistema Binário

    Dado, informação e conhecimento — e como o computador guarda o símbolo em bit, byte e hexadecimal.

  2. Guardar o significado do objeto no banco

    Por que documentar tabelas e colunas com MS_Description (extended properties) e como montar o dicionário a partir do catálogo.
